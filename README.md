# MIRROR // Personal AI

نسخة شخصية من مشروع الـRAG السابق. بدل ما يكون مساعد شغل، هذا المشروع يتعلم **طريقة كلامك أنت** من المحادثات والملفات التي ترفعها ويقترح ردودًا بنفس أسلوبك.

## Instagram — ارفع الـExport كما هو

تقدر ترفع:

- ملف Instagram export كامل بصيغة `.zip` حتى لو داخله صور وفيديو وصوت.
- ملف واحد مثل `message_1.json` مباشرة كما نزّلته Meta، بدون أي تعديل يدوي.
- عدة ملفات `message_1.json / message_2.json / ...`.

النظام يعمل تلقائيًا على:

- البحث داخل الـZIP عن ملفات رسائل Instagram فقط.
- تجاهل الصور والفيديوهات والصوت وباقي ملفات الـexport الثقيلة من ذاكرة الأسلوب.
- قراءة `sender_name`, `timestamp_ms`, و`content` فقط للرسائل النصية.
- إصلاح mojibake الخاص بتصدير Meta مثل `ØªÙ...` وتحويله للعربي/الإيموجي الصحيح.
- ترتيب الرسائل زمنيًا لأن Instagram export غالبًا يضع الأحدث أولًا.
- دمج أجزاء نفس المحادثة عندما تكون مقسمة إلى `message_1`, `message_2`, ...
- إزالة التكرار عند دمج الأجزاء.
- التعرّف على رسائل Fares من خلال `MY_NAMES`.
- بناء Voice Samples + أزواج **رسالة الطرف الآخر → ردك** لتقليد أسلوب الرد.

يوجد داخل الواجهة تبويب **الشاتات** يعرض المحادثات بشكل طبيعي بدل JSON، مع:

- قائمة الأشخاص.
- بحث بالاسم.
- عدد الرسائل.
- تمييز رسائلك عن رسائل الطرف الآخر.
- تحميل الرسائل القديمة على دفعات حتى لا تتجمّد الصفحة في الشاتات الكبيرة.

## WhatsApp وملفات أخرى

المشروع ما زال يدعم:

- WhatsApp exports بصيغة `.txt`.
- Telegram/Chat JSON عندما يحتوي sender/from + text/message/content.
- `.txt`, `.md`, `.csv` كذاكرة نصية شخصية.

## التشغيل

```bash
npm install
cp .env.example .env
```

ثم عدّل `.env` وضع مفتاح Groq الحقيقي:

```env
GROQ_API_KEY=gsk_xxxxxxxxx
GROQ_MODEL=openai/gpt-oss-120b
OWNER_NAME=Fares
MY_NAMES=Faresyared,Fares Yared,Fares,فارس
MAX_UPLOAD_MB=1024
MAX_ARCHIVE_TEXT_MB=512
MAX_JSON_ENTRY_MB=64
PORT=3000
```

بعدها:

```bash
npm start
```

وافتح Port 3000.

## أهم إعداد: MY_NAMES

`MY_NAMES` يحتوي كل الأسماء التي تظهر بها **أنت** داخل ملفات المحادثات، مفصولة بفواصل.

النسخة الحالية مجهزة مبدئيًا لـ:

```env
MY_NAMES=Faresyared,Fares Yared,Fares,فارس
```

إذا عندك اسم آخر يظهر داخل WhatsApp أو Telegram أضفه لنفس السطر.

## حدود الرفع

القيم الافتراضية:

- حتى 100 ملف في عملية الرفع.
- `MAX_UPLOAD_MB=1024`: حتى 1GB للملف الواحد، مناسب لملف Instagram ZIP كبير.
- `MAX_JSON_ENTRY_MB=64`: أكبر حجم لملف رسائل JSON واحد داخل ZIP.
- `MAX_ARCHIVE_TEXT_MB=512`: أقصى مجموع لنصوص الرسائل المفكوكة من ZIP.

يمكن رفع هذه القيم من `.env` إذا كان export أكبر.

## الخصوصية

- الملفات المرفوعة تحفظ داخل `memory/` محليًا على السيرفر.
- `memory/*` موجودة في `.gitignore` ولن تُرفع إلى GitHub بالخطأ.
- ZIP لا يتم فكّه إلى صور/فيديوهات على القرص؛ النظام يقرأ فقط ملفات الرسائل المطلوبة منه.
- قبل إرسال أمثلة إلى Groq يتم إخفاء أنماط واضحة لمفاتيح API وJWT وIBAN وأرقام مالية طويلة.
- الموديل موجه لعدم كشف معلومات خاصة من محادثة أخرى أو اختراع حقائق شخصية غير موجودة.

## ملاحظة

هذا **RAG + style mirroring** وليس fine-tuning. لذلك تقدر تضيف أو تمسح ملفاتك فورًا بدون إعادة تدريب موديل كامل.
