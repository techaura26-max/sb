# MIRROR // Personal AI

نسخة شخصية من مشروع الـRAG السابق. بدل ما يكون مساعد شغل، هذا المشروع يتعلم **طريقة كلامك أنت** من الملفات التي ترفعها ويقترح ردودًا بنفس أسلوبك.

## ماذا يفعل؟

- يقرأ WhatsApp exports بصيغة TXT.
- يقرأ Telegram/Chat exports بصيغة JSON عندما تكون الرسائل فيها تحتوي sender/from + text/message/content.
- يقبل ملفات TXT / MD / CSV كذاكرة نصية شخصية.
- يستخرج من الشاتات:
  - رسائلك كـ **Voice Samples** لتعلّم اللهجة والأسلوب.
  - أزواج **رسالة الطرف الآخر → ردك** لتعلّم كيف ترد في مواقف مشابهة.
- يبحث محليًا عن أقرب أمثلة ثم يرسل فقط الأمثلة المختارة إلى Groq.
- لا يوجد أي منطق عملاء، أسعار، دفع، إجراءات داخلية أو YallaPay.
- يوجد زر لمسح كل الذاكرة المرفوعة من السيرفر.

## التشغيل

```bash
npm install
cp .env.example .env
```

ثم عدّل `.env`:

```env
GROQ_API_KEY=gsk_xxxxxxxxx
GROQ_MODEL=openai/gpt-oss-120b
OWNER_NAME=Me
MY_NAMES=Me,Your WhatsApp Name,Your Telegram Name
PORT=3000
```

بعدها:

```bash
npm start
```

وافتح Port 3000.

## أهم إعداد: MY_NAMES

`MY_NAMES` يجب أن يحتوي كل الأسماء التي تظهر بها **أنت** داخل ملفات المحادثات، مفصولة بفواصل.

مثال:

```env
MY_NAMES=Faris,Fares,فارس
```

إذا لم يجد النظام اسمك داخل export، سيعامل الملف كذاكرة نصية فقط ولن يعتبر رسائل الأشخاص الآخرين جزءًا من أسلوبك.

## الملفات المدعومة

- `.txt`
- `.md`
- `.json`
- `.csv`

الحد الحالي: 100 ملف، وحتى 15MB للملف الواحد.

## الخصوصية

- الملفات المرفوعة تحفظ داخل `memory/` محليًا على السيرفر.
- `memory/*` موجودة في `.gitignore` ولن تُرفع إلى GitHub بالخطأ.
- قبل إرسال أمثلة إلى Groq يتم إخفاء أنماط واضحة لمفاتيح API وJWT وIBAN وأرقام مالية طويلة.
- الموديل موجه لعدم كشف معلومات خاصة من محادثة أخرى أو اختراع حقائق شخصية غير موجودة.

## ملاحظة

هذا **RAG + style mirroring** وليس fine-tuning. لذلك تقدر تضيف أو تمسح ملفاتك فورًا بدون إعادة تدريب موديل كامل.
