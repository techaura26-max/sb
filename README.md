# Instagram Chat Viewer

برانش مستقل لعرض Instagram message exports بدون AI وبدون رفع الملفات للسيرفر.

## التشغيل

```bash
git checkout instagram-chat-viewer
npm install
npm start
```

افتح Port 3000.

## الاستخدام

- **اختار JSONات**: لاختيار `message_1.json`, `message_2.json` وغيرها مباشرة.
- **اختار فولدر**: لاختيار فولدر Instagram export كامل؛ الصفحة ستقرأ ملفات JSON فقط.
- العربي والـemoji المشوه بسبب Meta encoding يتم إصلاحه داخل المتصفح.
- أجزاء نفس المحادثة يتم دمجها حسب المشاركين.
- الرسائل ترتب حسب `timestamp_ms` من الأقدم إلى الأحدث.
- الصور والفيديو والصوت لا تدخل في العرض؛ فقط الرسائل التي تحتوي `content` نصي.
- اضغط على **اسم الشات في أعلى المحادثة** لرؤية اسم/أسماء الملفات الأصلية التي جاءت منها المحادثة.
- عند اختيار فولدر، يظهر أيضًا `webkitRelativePath` حتى تعرف مكان الملف داخل export.

## الخصوصية

قراءة ملفات JSON تتم بالكامل في JavaScript داخل المتصفح. الملفات لا يتم POST أو Upload لها إلى السيرفر. السيرفر فقط يقدم ملفات الواجهة الثابتة.

> المتصفح لا يكشف مسار Windows الكامل مثل `C:\\Users\\...` لأسباب أمنية؛ اسم الملف نفسه يبقى كما هو، والمسار النسبي داخل الفولدر يظهر عند اختيار فولدر.
